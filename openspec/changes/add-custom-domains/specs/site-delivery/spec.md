## ADDED Requirements

### Requirement: サイトは環境ごとに定められた独自ドメインで配信される

サイトは、配信基盤が自動で払い出す名前ではなく、環境ごとに定められた独自ドメインで到達できなければならない（MUST）。環境が異なればドメインも異なっていなければならない（MUST）。

独自ドメインでの通信には、そのドメインに対して有効な証明書が提示されなければならない（MUST）。

#### Scenario: 独自ドメインでのアクセス

- **WHEN** 訪問者が環境の独自ドメインでサイトにアクセスする
- **THEN** その環境のサイトのページが配信される

#### Scenario: 証明書の検証

- **WHEN** 訪問者が独自ドメインに HTTPS で接続する
- **THEN** そのドメインに一致する有効な証明書が提示され、警告なく接続が確立する

#### Scenario: 環境ごとのドメイン

- **WHEN** staging と production のサイトのドメインを確認する
- **THEN** 互いに異なるドメインである

#### Scenario: 配信基盤の作り直し

- **WHEN** 配信基盤を作り直し、自動で払い出される名前が変わる
- **THEN** 訪問者が使うドメインは変わらない

## MODIFIED Requirements

### Requirement: サイトは CDN 経由で一般公開される

サイトは CDN を通じて配信され、閲覧に認証を要求してはならない（MUST NOT）。

#### Scenario: 訪問者によるアクセス

- **WHEN** 訪問者がサイトのドメインでサイトにアクセスする
- **THEN** 認証なしでページが表示される
