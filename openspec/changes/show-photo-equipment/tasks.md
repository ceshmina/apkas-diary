  - `dynamodb:LeadingKeys` を `ForAllValues:StringLike` で `PHOTO#*` に限る。`ENTRY#<年>` は権限の側で引けないままにする
  - 既存の `QueryPublishedEntries` のコメント（「ベーステーブルへの Query は与えない」）を、**なぜ目録だけは与えるのか**が読める形に書き足す。消して書き換えるのではなく、条件付きで開いたことが分かるように残す
- [ ] 1.2 staging に terraform apply して、増えたのが statement 1つだけであることを plan の差分で確かめる

## 2. 配信パスの規約（`src/lib/photo.ts`）

本文が知っているのは配信 URL だけで、そこから元写真のキーは**復元できない**（拡張子が落ちている）。前向きに組み立てたものどうしを突き合わせる（design.md 決定1）。

- [ ] 2.1 `photoPathOf(sourceKey)` を足す。配信キーからサイズ名を除いた部分（`2026/08/13/DSCF1234.webp`）を返す
  - `photoKeyOf` を `${size}/${photoPathOf(sourceKey)}` の形に書き直す。**規約が2箇所に分かれないようにする**。作る文字列は変わらない
- [ ] 2.2 `photoPathFromUrl(base, url)` を足す。配信 URL から配信パスを取り出し、基点が一致しないもの・段数が足りないものは `undefined` を返す
  - 各段は `decodeURIComponent` で戻す（`photoUrlOf` が段ごとに符号化しているため）。空白を含むファイル名で往復することを確かめる
  - **URL から `sourceKey` を逆に導く関数は作らない。** 導けない（`.jpg` / `.JPG` / `.HEIC` のいずれからも同じ URL になる）ことと、推測で埋めると外れた写真だけ静かに機材が出なくなることを、コメントに残す
- [ ] 2.3 配信パスから日付を取り出す手段を用意する。`photoSourceOf` と同じ規約（`YYYY/MM/DD/<ファイル名>`、暦上実在する日付）で判定する
- [ ] 2.4 `npm run check` を通す

## 3. 機材の字面（`src/lib/equipment.ts`）

- [ ] 3.1 目録の `PhotoExif` から、拡大表示に出す1行を組み立てる関数を作る（design.md 決定5）
  - 表は design.md 決定5。`model` のみ / `model, lensModel` / `lensModel` のみ / なし の4通り
  - **`make` は使わない。** EXIF の `Make` はメーカーの書いた字面がそのまま入っており、大文字の揺れを画面に持ち込むこと、`Canon EOS R6` のように `Model` が既にメーカー名を含む例があることを理由としてコメントに残す
  - レンズを出すかどうかは **`lensModel` が `model` を含むかどうか**だけで決める。大文字小文字は無視し、前後の空白は落として比べる
  - **メーカーや機種の一覧を持たない。** 一覧に載っていない端末が来た日に長い文字列がそのまま出ること、気づくのはその写真を拡大したときであることを、採らなかった理由として書き残す
  - どちらも記録がなければ `undefined` を返す。空文字を返さない（不在は不在として表す）
- [ ] 3.2 手元の値で4通りを確かめる。少なくとも iPhone（`LensModel` が機種名で始まる）と、レンズを交換する機材の1つを実データから取って確かめる
- [ ] 3.3 `npm run check` を通す

## 6. 拡大表示（`src/components/`）

- [ ] 6.1 `PhotoZoom.astro` の `figure` に、`figcaption` の下へ機材の行を足す（design.md 決定7）
  - `:empty { display: none }` で、記録のない写真では要素ごと消す（説明と同じ手）
- [ ] 6.2 体裁を整える。**新しい色も新しい大きさも増やさない**
  - 書体は `--font-ui`（欧文のラベル）。説明は本文系の字のままにし、**書体の違いが著者の言葉と機械の記録の違いに重なる**ことをコメントに残す
  - 色は白の不透明度 0.48（説明は 0.72）。暗幕の上での contrast が 4.5 を上回ることを書き残す
  - 大きさは前後の導線の日付と同じ 0.74rem・letter-spacing 0.08em
- [ ] 6.3 `photo-zoom.ts` の `Cell` と `Photo` に機材を足し、`fill()` が説明と同じように入れ替えるようにする

  - **`close()` で説明を消しているのと同じ扱いを機材にも与える**（`opacity = '0'`）。写真が本文へ帰るとき、機材の行だけが残ってはいけない
  - `place()` が説明の `opacity` を戻しているのと同じ場所で、機材も戻す
  - `aria-label` には入れない（いまの `dialog` の `aria-label` は「それが何の写真か」を言う言葉である）
