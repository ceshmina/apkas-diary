## Why

ポートフォリオ（`../apkas`、apkas.net）の配色が Sirka Blue のパレットに変わった。深い夜の青を軸に、淡い青の霞とやわらかい白を置き、わずかに紫を添えるもので、以前の「温かい紙の地にテラコッタ」とは別物である。

日記はその移行前の写しを持ったままでいる。地は `#faf8f5`、アクセントは `#b0512a` のテラコッタで、いまポートフォリオから日記へ辿ると、地の色もアクセントも変わる。[align-with-portfolio](../archive/2026-08-11-align-with-portfolio/proposal.md) で消したはずの「別のサイトに見える」が、出どころの側が動いたことでそのまま戻っている。

これは想定していた事態である。別リポジトリ・別配信で CSS を共有する手段がないため、日記は写しを持つと決めた。その帰結として「あちらを変えたときは、こちらも手で写し直す」ことを README にも書いてある。いまがその写し直しにあたる。

## What Changes

**基準値の色だけを、ポートフォリオの新しい値に写し直す。** 変数名・寸法・書体・角丸・部品の体裁・ページの構成には触れない。前回の align-with-portfolio が体裁の枠組みそのものを移す変更だったのに対し、こちらは既にある枠組みの中で色の値を差し替えるだけである。

**基準値（`src/styles/tokens.css`）**

- 明暗それぞれ7つ、計14個の値を置き換える。対応は前回定めたまま変わらない（`--fg` = `--ink`、`--fg-muted` = `--muted`、`--border` = `--line`、`--bg` / `--surface` / `--accent` / `--accent-soft` は同名）。
- 先頭のコメントに書いてあるパレットの説明を、Sirka Blue のものに差し替える。どの色がパレットのどれにあたるかを、前回と同じ形で残す。

**ブラウザの枠の色**

- `src/layouts/Base.astro` と `editor/src/layouts/Base.astro` の `theme-color` を新しい地の色にする。これは `tokens.css` の `--bg` を meta に書き写している箇所で、CSS 変数を読めないため2つ目の写しになっている。色を変えるときは必ず一緒に動かす必要がある。

### スコープ外

- **変数名と、色以外の基準値**。書体・本文の幅・角丸・字送りはポートフォリオ側でも変わっていない。
- **部品の体裁とページの構成**。ピル・囲み・ボタン・入力欄・ホバーの与え方は前回決めたままで、色の値だけが入れ替わる。
- **`--accent-alt`（Dusk Mauve）と `--shadow` の持ち込み**。ポートフォリオがこの2つを使うのは経歴の期間と円形アイコンの影で、日記にはどちらの要素もない。使い道のない基準値を先に置くと、次に色を足したくなったときの逃げ道になる。
- **写真の拡大表示（`PhotoZoom.astro`）**。暗幕の上に写真と説明が載るもので、ページの配色によらず常に暗い背景の上にある。前回と同じ理由でトンマナの対象にならない。
- **ポートフォリオ側（`../apkas`）の変更**。値の出どころはあちらにある。
- **写しを持つ構えそのものの見直し**。「あちらが変わってもこちらは変わらない」という弱さがこの変更で顕在化したが、別リポジトリ・別配信という前提は変わっておらず、CSS を物理的に共有する手段もないままである。仕組みで防ぐ話は、少なくともこの変更とは別に扱う。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

なし。`visual-identity` は「体裁はポートフォリオと同じ基準に従う」ことを要件としており、色の値そのものは要件に書かれていない（書けば、出どころが spec とポートフォリオの2つに増える）。この変更は要件を変えるものではなく、要件から外れていた実装を要件の側へ戻すものである。

したがって `.openspec.yaml` に `skip_specs: true` を置く。

## Impact

**基準値**

- `src/styles/tokens.css`: `:root` と `prefers-color-scheme: dark` の色、計14個。先頭のコメント。

**ブラウザの枠**

- `src/layouts/Base.astro`: `theme-color` の meta 2つ。
- `editor/src/layouts/Base.astro`: `theme-color` の meta 2つ。

**記録**

- `README.md`: 体裁の基準について書いた箇所に、パレットの名前が出てくる場合はあわせて直す。

**配信物**

- 全ページの CSS が変わる。マークアップは変わらない。URL の集合も、生成されるページ数も変わらない。
