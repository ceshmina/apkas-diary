## Purpose

生成された静的サイトを訪問者に届ける経路を定め、その経路以外からコンテンツに到達できないことを担保する。配信元のストレージを直接公開しないことで、公開範囲の制御を単一の入口に集約する。

## ADDED Requirements

### Requirement: サイトは CDN 経由で一般公開される

サイトは CDN を通じて配信され、閲覧に認証を要求してはならない（MUST NOT）。

#### Scenario: 訪問者によるアクセス

- **WHEN** 訪問者が CDN のドメインでサイトにアクセスする
- **THEN** 認証なしでページが表示される

### Requirement: 配信元のストレージは直接アクセスできない

配信元のオブジェクトストレージはパブリックアクセスを全面的に禁止し、CDN からのみ読み取れるように制限しなければならない（MUST）。

#### Scenario: ストレージへの直接アクセス

- **WHEN** 配信元バケットのオブジェクト URL に直接アクセスする
- **THEN** アクセスが拒否される

#### Scenario: CDN 経由のアクセス

- **WHEN** 同じオブジェクトに CDN 経由でアクセスする
- **THEN** 正常に配信される

### Requirement: 通信は HTTPS に限定する

サイトへの通信は暗号化されなければならない（MUST）。

#### Scenario: HTTP でのアクセス

- **WHEN** 訪問者が HTTP でサイトにアクセスする
- **THEN** HTTPS にリダイレクトされる

### Requirement: デプロイ後に更新内容が反映される

デプロイの完了後、訪問者には更新後の内容が配信されなければならない（MUST）。キャッシュにより古い内容が配信され続けてはならない（MUST NOT）。

#### Scenario: 内容を更新して再デプロイする

- **WHEN** エントリを更新してサイトを再生成しデプロイする
- **THEN** 訪問者には更新後の内容が配信される

#### Scenario: 削除されたページ

- **WHEN** 前回のデプロイに存在したページが今回の生成物に含まれない状態でデプロイする
- **THEN** そのページは配信されなくなる

### Requirement: 存在しないパスには 404 を返す

生成物に存在しないパスへのアクセスには、404 ステータスとエラーページを返さなければならない（MUST）。

#### Scenario: 存在しないパスへのアクセス

- **WHEN** 訪問者が生成物に存在しないパスにアクセスする
- **THEN** 404 ステータスとともにエラーページが表示される

### Requirement: デプロイはローカルの操作で完結する

サイトの生成とデプロイは、開発者のローカル環境からの操作だけで実行できなければならない（MUST）。この change の時点では CI/CD への依存を持ってはならない（MUST NOT）。

#### Scenario: ローカルからのデプロイ

- **WHEN** 開発者がローカル環境でデプロイ操作を実行する
- **THEN** 生成物が配信元へ反映され、CDN 経由で閲覧できる状態になる
