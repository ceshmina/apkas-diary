## Why

日記の体裁は、これまでポートフォリオ（`../apkas`、apkas.net）の写しとして決めてきた。[align-with-portfolio](../archive/2026-08-11-align-with-portfolio/proposal.md) で基準を移し、[align-color-palette](../archive/2026-08-23-align-color-palette/proposal.md) と [align-typography](../archive/2026-08-25-align-typography/proposal.md) はどちらも、あちらが動いたことに合わせた写し直しだった。この構えでは、日記の側から体裁を良くする余地がない。変えられるのは、あちらが変わったときに追いかけることだけである。

日記を、日記として見栄えのする体裁に作り直す。白地に黒を基調に、セリフ体を交えて組み、Web フォントを使う。いまの Sirka Blue の配色と、OS 任せの明朝・ゴシックは踏襲しない。方向は、3案の見本を比べたうえで「朱の一点」（大きな日付の数字と英字の見出し、朱を1色だけ）を土台に、本文を Zen角ゴシック New にした案で合意している。

## What Changes

**基準の出どころを日記に移す**

- **BREAKING** 体裁の基準をポートフォリオから切り離し、日記が自分で持つ。`src/styles/tokens.css` は「写し」ではなくなり、あちらが変わったときに写し直す運用（README に書いてあるもの）もやめる。ポートフォリオから辿ったときに同じサイトに見える、というこれまでの要件は手放す。
- **BREAKING** ダークモードをやめる。暗い設定の配色、`theme-color` の暗い側、`color-scheme: light dark` を削り、白い地の1通りにする。暗い設定の環境でも白地で示す。

**配色**

- 地 `#FFFFFF`、文字 `#111111`、淡い文字 `#6A6A6A`、罫線 `#E5E5E5`、アクセントは朱 `#C73E1D` の1色。
- 朱は面を塗らず、印と手応えにだけ使う（題字の点、日付の印、本文の区切り線、ホバー・フォーカス・いま居る場所）。リンクや題の文字色には使わない。

**書体（Web フォント）**

- 題字・日付の数字・英字の見出しは Instrument Serif、記事と一覧の題は Zen Old Mincho、本文と和文のラベルは Zen角ゴシック New、欧文のラベルは Instrument Sans。
- 題の明朝は、本文の Zen角ゴシック New と同じ作者による Zen のファミリーから選ぶ（Zen Old Mincho の 600）。候補を見本で見比べ、字面のそろい方と配信する量の軽さで決めた。
- 本文は Zen角ゴシック New の Regular 400。大きさはスマートフォン 15px、PC 15.5px。いまの本文（明朝 1.05rem）より小さく、行送り 2.0 で組む。
- 公開サイトの書体は、ビルド時に取得して公開サイト自身から配信する（Astro の Fonts API）。閲覧のたびに Google のサーバーへ問い合わせない。編集アプリケーションは同じ書体を Google Fonts から読む。

**組み方と部品**

- 日付は英語の略記で示す。月と曜日は先頭だけ大文字の略記（Sep、Mon）にする。一覧と日別ページでは日の数字を大きく置き、月・年と曜日を小さく添える（Sep 2026 / Sun）。前後の導線では1行で示す（Mon, Sep 21, 2026）。
- 英語にするのは見た目だけで、支援技術には和文の日付（2026年9月20日（日））を渡す。日別ページで日付を1度だけ・タイトルの有無で変えずに示すことは保つ。
- 年別・月別へのピルは数字と略記だけにする（2026、Sep）。「年」「月」は見た目から外し、読み上げには残す。
- 日別ページの下の一覧への導線を英語にする（Sep 2026 / 2026 / On this day）。読み上げには和文（2026年9月の一覧 など）を渡す。
- ページの見出しに、英字の見出し語（Recent・Archive など）か、その期間を表す語（2026、Sep）を大きく添える。和文の見出しは `h1` として残し、英字は飾りとして扱う。
- 前後の導線に `Newer` / `Older` の見出し語を添える。左が新しい側、右が古い側という向きは変えない。
- 押せるもの（ピル・ボタン）は丸く、囲みと入力欄は角を立てる。
- 編集アプリケーションも同じ基準に従う。プレビューと公開後の字面の一致は保つ。

### スコープ外

- **ページの構成・導線・URL**。英字の見出し語と、日付・導線の表記を除き、置くものは変えない。
- **和文のまま残すもの**。ページの和文の見出し（`h1`）、文書の題（`<title>`）、件数（「N 件」）、編集アプリケーションの日付。見出しと題は、読み上げや検索に使われる文字として和文に保つ。
- **Markdown の整形規則**（`src/lib/markdown.ts`）。本文の要素と、その並びは変わらない。
- **写真の拡大表示**（`PhotoZoom.astro`）。暗幕の上に写真を置くもので、ページの配色によらず暗い背景の上にある。これまでと同じく対象外とする。
- **ポートフォリオ側（`../apkas`）の変更**。今後あちらをどうするかは、日記とは別に決める。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `visual-identity`: 「ポートフォリオと同じ基準に従う」を「日記自身の基準に従う」に置き換える。「明暗どちらの設定でも読める」をやめ、白い地の1通りとアクセントの使いどころを定める。基準の出どころが1つであることに書体を含め、Web フォントの読み込みを待つあいだ・読み込めないときにも読めること、欧文で見せる日付を支援技術には和文で渡すこと、公開サイトの書体を第三者から読み込まないことを加える。

`diary-site-pages` の要件は変わらない。日付を1度だけ・同じ書式で示すこと、前後の導線の向き、タイトルの不在を文言で示さないことは、新しい見せ方でもそのまま満たす。

## Impact

**基準値と書体の定義**

- `src/styles/tokens.css`: 全面的に書き換える。配色、書体の役割、本文の大きさ、角丸。暗い設定のブロックを削る。
- `src/styles/base.css`: 字送り、見出し、本文、リンク、区切り線、ピル、節の題、フォーカス、`color-scheme`。
- 新設 `src/styles/fonts.ts`: 使う書体と太さの一覧。公開サイトの Fonts API の設定と、編集アプリケーションの読み込みの両方がここから作られる。
- `astro.config.ts`: `fonts` の設定。

**公開サイト**

- `src/layouts/Base.astro`: 書体の読み込み、`theme-color`、ヘッダー・フッター。
- `src/components/EntryList.astro`: 日付の見せ方と行の体裁。
- `src/pages/` の全6種: ページの見出し、前後の導線、一覧への導線、年・月のピル。
- `src/lib/date.ts`: 月と曜日の英語の略記と、日付を英語の部分に分けて返す関数を足す。読み上げ用の和文には既存の `formatDateJa` を使う。

**編集アプリケーション**

- `editor/src/layouts/Base.astro`: 書体の読み込み、`theme-color`、題、囲み・ボタン・入力欄・ピルの体裁。
- `editor/src/pages/`: アクセント色と角丸を参照している箇所を見直す。

**記録**

- `README.md`: 「体裁の基準はポートフォリオにある」の節を書き換える。

**配信物**

- 全ページの HTML と CSS が変わる。URL の集合と、生成されるページ数は変わらない。
- 公開サイトの配信物に書体のファイルが約370個・約5.4MB 加わる。閲覧者が読むのは、そのページで使う文字を含む断片だけである。
- 追加の npm パッケージはない（Fonts API は Astro に含まれる）。
