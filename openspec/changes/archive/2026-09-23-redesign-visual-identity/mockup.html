本文書体

本文は「薄めのサンセリフ」でよいか

3案の本文書体を、同じ文章・同じ大きさ（16px）・同じ文字色（#161616）で並べました。参考に、明朝で組んだ本文も置いています。太さを切り替えて比べてください。

  • Light 300 は、Retina の Mac や iPhone では軽やかで上品に見えます。一方、Windows の拡大率 100% の画面では線が細くなり、長い文章ではかすれて見えることがあります。
  • 薄く見せたいときは、文字を灰色にするより太さで軽くするほうが、読みやすさを保てます。3案とも本文の色は黒に近いままにしています。
  • Noto Sans JP は太さを連続で選べるので、300 と 400 のあいだ（350 など）に置くこともできます。

決まったこと

  1. 軸にする案 — B（朱の一点）。
  2. 本文の書体と太さ — Zen角ゴシック New の Regular 400。大きさはスマートフォン 15px、PC 15.5px。ラベルに混ざる和文も同じ書体にそろえる。
  3. 英字の混ぜ方 — 日付は英語の略記（Sep 2026 · Sun、導線では Mon, Sep 21, 2026）。年別のピルは数字だけ（2026）、一覧への導線も英語（Sep 2026 / 2026 / On this day）。見出しに Recent / Archive などの英字を添え、和文の見出しはラベルとして残す。読み上げには和文の日付を渡す。
  4. 題の明朝 — Zen Old Mincho 600（推奨・比較中）。本文の Zen角ゴシック New と同じ Zen のファミリー。
  5. アクセントの色 — 朱 #C73E1D をひとつ。題字の点・日付の印・区切り線・手応えに絞って使う。

こちらで決めておくこと

  • 編集アプリケーションも同じ基準に揃えます。プレビューと公開後の字面を一致させるためです。
  • 「ポートフォリオと同じ基準に従う」という今の要件は外し、日記が自前の基準を持つ形にします。
  • 暗い設定の配色と、ブラウザの枠の暗い側の色はなくします。
  • Web フォントは日記のサイト自身から配信する方向で検討します（閲覧のたびに Google のサーバーへ問い合わせない）。
