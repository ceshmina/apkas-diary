## 2. 押せるようにする

## 3. 開閉を作る

- [x] 3.1 押された `img` の矩形を測り、中央のセルに `src` を移して `decode()` の完了を待ってから `showModal()` する
  - 同じ URL は本文で読み込み済みなので実際の待ちは生じない。読めなかった場合も開く（位置と大きさは要素から取れる）。
- [x] 3.2 元の矩形から、viewport に縦横比のまま収まる最大の矩形へ `transform` で遷移させる（FLIP）。実寸を上限にしない
  - `invert()` が「`to` にある要素を `from` の位置に見せる transform」を返す。当ててから外すと動いたように見える。
  - 収まる最大の矩形は CSS が決める（セルは flex、画像は `max-width/max-height: 100%`）。JS は矩形を測るだけで、大きさの計算を持たない。
  - 画像の枠 `.photo-zoom-frame` を1つ挟んでいる。画像に直接 `max-height: 100%` を与えると、説明の高さを数えないまま画面に収めようとしてはみ出す。
- [x] 3.3 開いているあいだ、今見ている写真に対応する本文側の `img` を `visibility: hidden` にする
- [x] 3.4 `figure` から開いた場合だけ、`figcaption` の文を拡大表示に出す。`table` の並びの `td[colspan]` は出さない
  - `captionOf()` は `img.closest('figure')` の `figcaption` しか読まない。
- [x] 3.5 クリック（写真の上・外側とも）と Esc（`cancel` イベント）で閉じる。クリックとして扱うのは、軸ロックが起きなかったときだけにする
- [x] 3.6 閉じるときは、その時点で本文側の `img` の矩形を測り直してから戻す

  - `focus({ preventScroll: true })`。位置は 5.7 で既に合わせてあるので、フォーカスのためにさらに動かす必要がない。

  - CSS の `transition` ではなく、Web Animations API に渡す時間を 0 にする形にした。開閉も移動も動きの完了を待って次の状態へ進む作りなので（閉じ終わってから `dialog.close()`、移り終わってからセルの役割を入れ替える）、CSS 側で切ると待っている合図まで消える。design.md の決定3も実装に合わせて書き直した。

## 4. ジェスチャを受ける

- [x] 4.1 `pointerdown` / `pointermove` / `pointerup` でドラッグを受け、動き始めの十数 px で縦か横かを決める（軸ロック）。決めたあとはもう一方の成分を無視する
  - 12px で確定。`setPointerCapture` を使うので、指が写真の外に出ても追い続ける。
- [x] 4.2 拡大表示に `touch-action: none` を当て、ブラウザのスクロール・pull-to-refresh・横スワイプによる履歴移動に操作を取られないようにする
  - あわせて `overscroll-behavior: contain`、セルに `user-select: none`（ドラッグで文字が選択されないように）。
- [x] 4.3 縦のドラッグ：写真を指に追従させ、暗幕を薄くする。上下どちらでも、距離または速度が閾値を超えたら閉じる。閾値は誤爆しない深さに取る
  - 画面の高さの18%、または 0.5px/ms。横（幅の14%）より深い。閉じるほうが取り返しの手数が多いため。
  - 追従はセルごと動かす（`translateY` と縮小）。写真と説明が一緒に動く。
- [x] 4.4 閾値に届かないまま離した場合は、縦横とも動かした量を戻して拡大表示に帰る
- [x] 4.5 マウスのホイールは追従させず、累積量が閾値を超えたところで閉じる。向きは上下どちらでもよい
  - 80px で閉じる。400ms 以上間が空いたら数え直す。少し動かして止めたものが、しばらく後の少しと足されて閉じるのは続きの動作として繋がっていない。
