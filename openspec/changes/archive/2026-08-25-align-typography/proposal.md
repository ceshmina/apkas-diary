## Why

ポートフォリオ（`../apkas`、apkas.net）の組み方が変わった。Web フォントは増やさないまま、OS 標準の明朝とゴシックを使い分けて階層をつける形になり、あわせて装飾が削られている。角丸は 12px から 2px へ、タグは塗りつぶしのピルから細い枠へ、リンクのホバーで浮き上がる動きは廃止された（`../apkas` の `b88559d`）。

日記はその前の写しを持ったままでいる。書体は1つ（ゴシック）、角丸は 12px と 8px、ピルは塗りつぶし、箱のリンクはホバーで浮き上がる。いまポートフォリオから日記へ辿ると、字面も箱の硬さも変わる。[align-color-palette](../archive/2026-08-23-align-color-palette/proposal.md) が色について直したのと同じずれが、今度は組み方と装飾の側に開いている。

原因も前回と同じである。別リポジトリ・別配信で CSS を共有する手段がないため、日記は写しを持つと決めた。その帰結として「あちらを変えたときは、こちらも手で写し直す」ことを README にも書いてある。いまがその写し直しにあたる。

## What Changes

**書体・角丸・装飾の基準を、ポートフォリオの新しいものに写し直す。** 配色には触れない（あちらでも変わっていない）。ページの構成、本文の幅、要素の配置も変えない。

**基準値（`src/styles/tokens.css`）**

- `--font` を `--font-sans` に改め、明朝の `--font-serif` を足す。値と名前はあちらのまま写す。
- `--radius` を 12px から 2px にする。
- `--radius-sm`（8px）を廃す。角丸が 2px になれば「横に長い箱ほど丸みが目立つ」という、この値を作った理由そのものが消える。
- `--accent-soft` を廃す。ピルの塗りをやめると使い道がなくなり、あちらも同じ理由でこの変数を削っている。

**書体の使い分け（`src/styles/base.css` ほか）**

- 地の書体はゴシックのまま。そのうえで、**名前・見出し・本文だけを明朝で組む**。あちらと同じく `font-weight: 500`（游明朝が Light に落ちるのを防ぐ）と、見出し・名前には約物を詰める `palt` を添える。
- 明朝にするのは、サイトの題（`.site-title` / `.app-title`）、`h1` / `h2`、エントリ本文、一覧のエントリ題。
- **0.9rem 以下のラベル・注記はゴシックのまま**にする。小さい字の明朝はかすれる、というのがあちらの判断で、日記にも同じ大きさの文字が多くある（日付、件数、節の題、ピル、フォーム）。
- エントリ本文は、明朝が同じ級数で小さく見える分を上げる（1.05rem / 行送り 2.05 / 字送り 0.04em）。**この体裁は公開サイトと編集アプリケーションのプレビューが共に読む場所に置く。** 片方だけに書くと、プレビューと公開後の字面がずれる。

**装飾を削る**

- ピル（`.pill`）の塗りをやめ、細い枠だけにする。角丸は 999px から `--radius` へ。あちらの `.tags` と同じ体裁になる。
- 塗りが担っていた「際立たせる側／そうでない側」の見分けを付け直す。淡い側（`is-quiet`）は囲みを持たない側にし、いま見ている年（`aria-current`）は枠をアクセント色にする。詳細は design で決める。
- 箱のリンクがホバーで浮き上がるのをやめ、枠の色だけを変える（あちらの `.link:hover` と同じ）。
- フォーカス環を 2px から 1px にし、角丸を `--radius` に揃える。
- 見出しの太さを 600 から 500 にする。強さは字の大きさと字送りで出す。
- 節の題（`.section-title`）を、あちらの `.section__title` と同じ字面（ゴシック・600・0.75rem・字送り 0.24em）にする。`h2` が明朝になるため、ここは明示的にゴシックへ戻す必要がある。

### スコープ外

- **配色**。ポートフォリオ側でも変わっておらず、14個の値はそのままでよい。`theme-color` の meta も動かさない。
- **本文の幅（`--page`）とページの構成**。あちらでも変わっていない。
- **`--accent-alt`（Dusk Mauve）と `--shadow` の持ち込み**。前回と同じ理由で、日記に対応する要素がない。
- **`strong` の扱い**。あちらは `strong` をアクセント色にしており日記はしていないが、この差は今回のコミットで生じたものではなく、前からある。まとめて直すと、この変更で何が変わったのかが読めなくなる。
- **写真の拡大表示（`PhotoZoom.astro`）**。暗幕の上に写真を置くもので、ページの配色・書体によらず常に暗い背景の上にある。前回・前々回と同じくトンマナの対象にならない。
- **`textarea` の等幅**。書くための面であり、あちらに対応する要素がない。
- **ポートフォリオ側（`../apkas`）の変更**。値の出どころはあちらにある。
- **写しを持つ構えそのものの見直し**。前回と同じく、別リポジトリ・別配信という前提は変わっていない。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

なし。`visual-identity` は「体裁はポートフォリオと同じ基準に従う」ことを要件としており、書体の名前も角丸の値も要件には書かれていない（書けば、出どころが spec とポートフォリオの2つに増える）。この変更は要件を変えるものではなく、要件から外れていた実装を要件の側へ戻すものである。前回 align-color-palette が色について同じ立場を取っている。

したがって `.openspec.yaml` に `skip_specs: true` を置く。

## Impact

**基準値**

- `src/styles/tokens.css`: `--font` の改名と `--font-serif` の追加、`--radius` の値、`--radius-sm` と `--accent-soft` の削除、先頭のコメント。

**共有する体裁**

- `src/styles/base.css`: 地の書体、明朝で組む要素の宣言、`h1` / `h2`、エントリ本文（`.prose`）、`.pill`、`.section-title`、フォーカス環、`pre` の角丸。

**公開サイト**

- `src/layouts/Base.astro`: `.site-title` の書体。
- `src/components/EntryList.astro`: エントリ題の書体。
- `src/pages/[year]/[month]/[day].astro`: 本文に `.prose` を当てる。
- `src/pages/404.astro`: 本文に `.prose` を当てる。

**編集アプリケーション**

- `editor/src/layouts/Base.astro`: `.app-title` の書体、ボタン・入力欄の角丸、ホバーの浮き上がりの削除。
- `editor/src/pages/entries/[date].astro`: プレビューに `.prose` を当てる、写真の角丸。
- `editor/src/pages/photos/uploaded.astro`: 写真の角丸。
- `editor/src/pages/index.astro`: 年の絞り込みのピルに添えたコメント（塗りに触れている）。

**記録**

- `README.md`: 体裁の基準について書いた箇所を見て、書体や角丸の具体に触れている場合は直す。

**配信物**

- 全ページの CSS が変わる。マークアップは `.prose` の付与だけが増える。URL の集合も、生成されるページ数も変わらない。
