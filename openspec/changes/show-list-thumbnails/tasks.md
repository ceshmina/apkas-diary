  - 属性値の `&amp;` は `&` に戻す（`withEquipmentInRaw` と同じ扱い）

## 3. 置き方（案 A′ 題の下に並べ、入りきらない日は白に溶かす）

design.md 決定6。見本（https://claude.ai/artifact/84EXkG9ECFwMhiSHTRJ878 の A′）と同じ組みにする。

- [x] 3.1 スマートフォン幅: 題のある行は題の下に3段目として、題のない行は題の位置に並べる
  - 題のない行の添え書きは、縮小画像のある行では1段目に置く（数字の高さの真ん中に置くのは、縮小画像のない行だけ）
- [x] 3.2 PC 幅（`min-width: 42.5rem`）: 題のある行は題の列の下に、題のない行は題の列に並べる
- [x] 3.3 縮小画像を正方形にし、大きさを列の幅から決める
  - `grid-auto-flow: column` と `grid-auto-columns: calc((100% - N * <間隔>) / (N + 0.5))`。並びは `overflow: hidden`
  - N は画面の幅で段を変える: 〜27rem（432px）で 5、〜34.5rem（552px）で 7、〜42.5rem（680px）で 9、PC 幅で 8。N をカスタムプロパティに置き、段ごとにそれだけを替える
  - **半端な「N 枚と半分」にする理由**（入りきるかどうかを段の中では枚数だけで決め、CSS だけで見分けるため）と、**段を変える理由**（大きさを 36〜58px ほどに保つため。N を固定すると 680px 手前で約 100px になる）をコメントに残す
- [x] 3.4 HTML に載せるのは1行10枚まで（いちばん多く見える段の 9.5 枚ぶん）。「+N」は置かない
- [x] 3.5 入りきらない行だけ、並びの右端を地の白に溶かす
  - 段ごとに N+1 枚目があるとき（`:has(> img:nth-child(6))`・`(8)`・`(10)`、PC 幅では `(9)`）だけ `mask-image` の gradient を当て、段が上がるたびに下の段での当て方を打ち消す
  - 溶かす幅は、最後の1枚の大きさから決める（見本では 1.15 枚ぶん）
  - 入りきる行（その段で N 枚まで）に溶かしが当たらないこと
  - `:has()` を解さないブラウザでは溶かしが当たらず、半分の1枚が切れて見えるだけで、並びが崩れないこと
  - `-webkit-mask-image` を並べて書いたところ、CSS の圧縮が打ち消しの `none` の側だけ接頭辞つきを落とした。別のプロパティとして扱う古いブラウザでは入りきる行に溶かしが残るので、`mask-image` だけにした
  - 320・375・431・433・480・551・553・600・679・680・1024px のすべてで、溶かしが当たる行と実際にはみ出している行が一致した（8枚の行は 551px まで溶け、553px 以上と PC では溶けない）。大きさは 36.3〜57.5px で、どれも正方形
