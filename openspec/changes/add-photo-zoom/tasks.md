## 1. 拡大表示のコンポーネントを置く

- [ ] 1.1 `src/components/PhotoZoom.astro` を作り、空の `<dialog>` と、その中に画面幅ぶんのセルを3つ横に並べたトラック（各セルに `img`、中央のセルに `figcaption`）を置く。暗幕は `::backdrop` に書く
- [ ] 1.2 同コンポーネントに `<script>` を置き、`showModal` を持たない環境では以降の組み立てを一切行わずに終わることを最初に書く
- [ ] 1.3 `src/pages/[year]/[month]/[day].astro` からコンポーネントを読み込む。日別ページ以外からは読み込まない

## 2. 押せるようにする

- [ ] 2.1 スクリプトから、本文（`.body`）の `img` のうち `a` の中にないものを本文の出現順に集め、`<button type="button">` で包む。この配列がそのまま写真の並びになる
- [ ] 2.2 `button` の既定の体裁を消し（`padding` / `border` / `background`）、`cursor: zoom-in` を当てる。このスタイルはスクリプトが付ける class にだけ効かせ、JS が動かないページに現れないようにする
- [ ] 2.3 `figcaption` があればその文を、なければ既定の文言を `aria-label` に与える
- [ ] 2.4 包んだあとに `table-layout: fixed` の列幅と `figure` の間隔が変わっていないことを、生成物で確かめる

## 3. 開閉を作る

- [ ] 3.1 押された `img` の矩形を測り、中央のセルに `src` を移して `decode()` の完了を待ってから `showModal()` する
- [ ] 3.2 元の矩形から、viewport に縦横比のまま収まる最大の矩形へ `transform` で遷移させる（FLIP）。実寸を上限にしない
- [ ] 3.3 開いているあいだ、今見ている写真に対応する本文側の `img` を `visibility: hidden` にする
- [ ] 3.4 `figure` から開いた場合だけ、`figcaption` の文を拡大表示に出す。`table` の並びの `td[colspan]` は出さない
- [ ] 3.5 クリック（写真の上・外側とも）と Esc（`cancel` イベント）で閉じる。クリックとして扱うのは、軸ロックが起きなかったときだけにする
- [ ] 3.6 閉じるときは、その時点で本文側の `img` の矩形を測り直してから戻す
- [ ] 3.7 閉じ終わったらトラックを空に戻し、本文側の `img` の `visibility` を戻し、キーボードの位置が押した `button` に戻ることを確かめる
- [ ] 3.8 `prefers-reduced-motion` のとき、CSS 側で `transition` を無効にする。JS の手順は変えない

## 4. ジェスチャを受ける

- [ ] 4.1 `pointerdown` / `pointermove` / `pointerup` でドラッグを受け、動き始めの十数 px で縦か横かを決める（軸ロック）。決めたあとはもう一方の成分を無視する
- [ ] 4.2 拡大表示に `touch-action: none` を当て、ブラウザのスクロール・pull-to-refresh・横スワイプによる履歴移動に操作を取られないようにする
- [ ] 4.3 縦のドラッグ：写真を指に追従させ、暗幕を薄くする。上下どちらでも、距離または速度が閾値を超えたら閉じる。閾値は誤爆しない深さに取る
- [ ] 4.4 閾値に届かないまま離した場合は、縦横とも動かした量を戻して拡大表示に帰る
- [ ] 4.5 マウスのホイールは追従させず、累積量が閾値を超えたところで閉じる。向きは上下どちらでもよい

## 5. 写真のあいだを移る

- [ ] 5.1 中央のセルの前後に、並びの隣の写真（medium）をあらかじめ入れておく。端では隣のセルを空にする
- [ ] 5.2 横のドラッグでトラックを指に追従させる。距離または速度が閾値を超えたら1セルぶん送り、添字を進めて3つのセルの中身を詰め直す
- [ ] 5.3 並びの端でさらに進めようとする動きには抵抗をかけ（動かした量の一部だけ動かす）、離したら元に戻す。折り返さない
- [ ] 5.4 写真を移ったら、本文側の `visibility` を前の写真から新しい写真へ移し、`figcaption` も入れ替える。説明のない写真ではその場所ごと消す
- [ ] 5.5 キーボードの左右キーに同じ移動を割り当てる（`←` が並びの手前、`→` が先）。端では何も起きない
- [ ] 5.6 写真が1枚だけの日記では、左右へ動かしても元に戻るだけになることを確かめる
- [ ] 5.7 移ったあとに閉じるとき、今見ている写真が画面の外にあれば `scrollIntoView` で画面内に入れ、そのうえで矩形を測り直して戻す

## 6. large への差し替え

- [ ] 6.1 開くアニメーションの完了後に、`src` の `/medium/` を `/large/` に置き換えた URL を `new Image()` で読み、成功したら中央のセルの `src` を差し替える。隣のセルは medium のままにする
- [ ] 6.2 写真を移ったら、移った先で改めて差し替えを始める
- [ ] 6.3 `/medium/` を含まない `src`、読み込みの失敗、閉じたあと・別の写真へ移ったあとに読み終わった場合は、いずれも何もしない。読み込み中を示す表示も出さない
- [ ] 6.4 差し替えの前後で拡大表示の位置と大きさが動かないことを確かめる
